# Operation-a-Laboratory
This repo is a help for students on Industrial Engineer to understand about OR basic models. Since Linear Programing until More complicated problems. I used CLAUDE to make the code. I use the theory concept of Hiller and Taha books about OR. I make the activities of labs with a new problems.
